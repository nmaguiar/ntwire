How ntwire works

ntwire is a userspace WireGuard multi-tunnel service. A client authenticates to a server, receives only the tunnel grants it is allowed to use, then sends permitted traffic through encrypted transport.

A direct connection

Your computerntwire-gui or CLI
ntwire-serverauthentication and grants
Approved servicefixed TCP target

The client authenticates with an SSH key or OIDC. The server grants only configured targets; the client opens local listeners for them.

Control-plane requests are protected with TLS. The data plane uses WireGuard; when UDP is unavailable, ntwire can use an authenticated WebSocket transport. Transport selection should not change which grants apply.

The relay does not terminate the client’s TLS or WireGuard session. It forwards opaque traffic to a registered server.
